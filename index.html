Evaluates F(ω) = ∫f(t)e−iωt dt numerically, over the finite range you give in place of −∞ to ∞ — wide bounds approximate the true (improper) transform for functions that decay away from the origin.

A quick-reference sheet of the standard identities. To evaluate an actual trig expression, use Calculate — sin, cos, tan and their inverse and hyperbolic forms all work there.

Pythagorean

sin²x + cos²x = 1
1 + tan²x = sec²x
1 + cot²x = csc²x

Reciprocal & Quotient

csc x = 1 / sin x
sec x = 1 / cos x
cot x = 1 / tan x = cos x / sin x
tan x = sin x / cos x

Co-function (degrees)

sin(90° − x) = cos x
cos(90° − x) = sin x
tan(90° − x) = cot x

Sum & Difference

sin(x ± y) = sin x cos y ± cos x sin y
cos(x ± y) = cos x cos y ∓ sin x sin y
tan(x ± y) = (tan x ± tan y) / (1 ∓ tan x tan y)

Double Angle

sin 2x = 2 sin x cos x
cos 2x = cos²x − sin²x = 2cos²x − 1 = 1 − 2sin²x
tan 2x = 2tan x / (1 − tan²x)

Half Angle

sin(x/2) = ±√((1 − cos x)/2)
cos(x/2) = ±√((1 + cos x)/2)
tan(x/2) = ±√((1 − cos x)/(1 + cos x))

Triangles

a/sin A = b/sin B = c/sin Claw of sines
c² = a² + b² − 2ab cos Claw of cosines
